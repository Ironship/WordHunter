Export and import packages

The ZIP package contains a separate YAML file for every word and book, plus all PDF page images. Move it safely between desktop and Android.

Import keeps other data. If the same record exists on both devices, Word Hunter keeps the one with the newer updatedAt stored in YAML.

Books, words and settings

The full package includes books, text, PDF images, vocabulary, learning progress and settings.

Words only

A small package with words, translations, statuses and change dates, without books or images.

Other tools

Anki and data cleanup

Exchange vocabulary with Anki

TSV exports words, translations, the first context, and optional articles. Importing TSV adds or updates vocabulary, but does not transfer settings, books, or profiles.

Exported statuses
Choose which word statuses are included in the TSV. Anki receives word, translation, context, and optional article columns.

Clear word database

Removes all saved words, translations, and learning progress for this language.

Clear library

Removes all custom texts and resets the book list while keeping your word database.
