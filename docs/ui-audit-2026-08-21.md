## Rejected / deferred (with reasons)

- **Breakpoint consolidation (500/540/700/760/780 → {540,780,1080})**: would
  shift reviewed layouts in the 500–780px band; defer to a dedicated pass with
  visual probes. Documented, not done.
- **rgba-white in nav-item hover / black rgba shadows → tokens**: sidebar is
  always-dark so rgba-white works; shadow unification is a visual-risk sweep
  touching ~12 components. Deferred.
- **translator-popup.html "dead" double box-shadow**: NOT dead — it is the
  rgba fallback for engines without `color-mix()`, deliberately pinned by
  `theme.test.js`. First attempt to remove it broke the pin; reverted
  byte-identically. Lesson recorded: check test pins before removing
  "overridden" declarations.
- **God-object file splits** (styles.css 4761 lines, book-import.ts 1257,
  settings.ts 1041): styles.css is read/pinned directly by ~10 test files
  (size budget, theme parity, loading, ocr-export-progress-style,
  css-verifiability…); TS splits change dist paths consumed by
  frontend-tests and the focused-regressions mock maps. Each split needs its
  own campaign with test re-pinning — out of scope for a UI-polish pass.
