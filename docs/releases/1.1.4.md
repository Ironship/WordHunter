# Word Hunter 1.1.4

A small fix release for 1.1.3. The interface font is now part of the app, and
Word Hunter Pocket states the same minimum Android version everywhere. Install
it over 1.1.3 directly.

## Fixes

- **Interface font** — the app used to fetch its Inter font from Google's font
  servers every time it started, and fell back to a system font when you were
  offline. The font now ships inside the app, so nothing is requested from
  Google when it starts and the interface looks the same with or without a
  connection.
- **Minimum Android version** — Word Hunter Pocket now lists Android 8.0 as its
  minimum version in the install package, matching what the app already
  requires. Devices running Android 7 can no longer install it.

## Known issues

- Scanned PDFs and images in languages other than Chinese and English are
  read with the bundled Chinese and English model, which can miss letters
  such as ä, ł or Cyrillic. You can add a model for your language as the
  [OCR model notes](https://github.com/Ironship/WordHunter/blob/main/src-tauri/ocr-runtime/README.md)
  describe.
