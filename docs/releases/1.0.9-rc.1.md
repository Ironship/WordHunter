# Word Hunter 1.0.9-rc.1 — Six fixes: case-insensitive vocab, auto-hide hints, content-sized sheet, responsive buttons, correct Ease Factor graph, desktop image OCR

This prerelease addresses six issues reported by users. Existing vocabulary, books, and sync records remain compatible.

## Highlights

- **Case-insensitive vocabulary identity:** Words differing only in letter case (Am/AM/am, der/Der/DER) are now treated as a single vocabulary entry across all languages. The preferred display spelling is preserved; duplicate entries merge on load with field-aware precedence (status follows its timestamp, schedule follows its timestamp, metadata keeps newest non-empty values).

- **Mobile flashcard guidance auto-hides:** The onboarding prompt "What does this word mean? Reveal the answer, then rate your recall" stops appearing after three successful in-text reviews. The counter synchronizes across devices via the existing preference sync.

- **Content-sized Android reader sheet:** The bottom word panel now expands only to the height of its enabled elements. Short cards no longer create large empty gaps; long cards scroll within the safe-area bound.

- **Five recall buttons fit narrow screens:** The in-text review grading buttons (1–5) use a responsive five-column grid with shrinkable columns and reduced gaps. All five fit in one row on ~280px viewports while maintaining ≥44px touch targets and 52px height. Localized accessible labels now include the visible numeral and correct quality semantics.

- **Correct Ease Factor Distribution graph:** The statistics and flashcard graphs now use six contiguous bins aligned with SM-2 semantics: ≤1.3 (leeches), (1.3,1.6], (1.6,2.0], (2.0,2.5], (2.5,3.0], >3.0. FSRS cards are excluded; missing/finite EF defaults to 2.5; no values are discarded.

- **Desktop image OCR import:** The same library import button and workflow used for PDF OCR now accepts JPG, JPEG, PNG, and WebP files on Windows and Linux. Files are validated by extension, MIME type, and magic bytes; EXIF orientation is applied; transparency is composited onto white; images are scaled to the OCR render size. Android and macOS image OCR remain unavailable (no bundled PaddleOCR runtime).

### Android upgrade note

The prerelease APK uses version code `100000901` (base `1000009` × 100 + `1`). It will **not** update a stable 1.0.8 install because the stable version code is `100000899` and prereleases sort before stable. Testers should install the prerelease APK separately or uninstall the stable version first.

### Installing on macOS

The DMG is ad-hoc signed and not notarized. If macOS blocks the first launch, open **System Settings → Privacy & Security**, choose **Open Anyway**, and confirm the launch.

### Known limitations

- Android does not bundle the PaddleOCR runtime; image OCR is disabled on Pocket.
- macOS does not currently bundle the OCR runtime; image OCR is disabled on the DMG.
- Prerelease artifacts are not submitted to the Google Play Store, Microsoft Store, Snapcraft, AUR, or Nixpkgs.
- The DEB package uses version `1.0.9~rc.1` (Debian revision) so it sorts correctly before the final `1.0.9`.
