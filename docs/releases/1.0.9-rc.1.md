# Word Hunter 1.0.9-rc.1

Six focused fixes from user feedback.

| # | Issue | Fix |
|---|-------|-----|
| 1 | Words differing only by case (Am/AM/am) treated as separate vocabulary entries | **Case-insensitive canonicalization** — Unicode NFC + locale-aware folding (Turkish I→ı, German ß→ss, Greek ς→σ). Display spelling preserved; duplicates merge on load; sync tombstones prevent alias resurrection. |
| 2 | Mobile flashcard hint "What does this word mean?" never disappears | **Auto-hide after 3 successful reviews** — counter persists & syncs across devices (`max` merge). |
| 3 | Android reader bottom sheet expands to full screen leaving huge empty gaps | **Content-sized expansion** — sheet grows only to enabled elements' height; long content scrolls; safe-area insets respected. |
| 4 | Five recall buttons don't fit on narrow phones (only 3 visible) | **Responsive 5-column grid** — shrinkable columns, 4px gaps, ≥44px touch targets at 280px viewport; localized `aria-label` includes numeral. |
| 5 | Ease Factor Distribution graph uses wrong bins, drops EF > 3.0 | **Correct SM-2 bins** — ≤1.3, 1.3–1.6, 1.6–2.0, 2.0–2.5, 2.5–3.0, >3.0; FSRS excluded; missing EF defaults to 2.5. |
| 6 | PDF OCR import exists but no image OCR | **Desktop image OCR** (JPG/PNG/WebP) via same local PaddleOCR pipeline: magic-byte validation, EXIF orientation, alpha→white, 1800px scale, single-page reader record. Android/macOS disabled (no bundled runtime). |
