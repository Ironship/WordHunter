# Word Hunter 1.0.9-rc.5

This release candidate keeps the rc.3 performance and Android startup work and
improves large backup, PDF, export, import, and synchronization workflows.

## Changes

- Remove the 32 MB Android JSON backup export limit.
- Remove the 128 MB portable JSON backup import limit.
- Increase Android PDF import and rendering limits to 400 MB.
- Replace native Syncthing pairing prompts with an application-styled dialog.
- Show busy feedback while JSON and Anki exports are prepared and saved.
- Show import progress while a backup file is being read.
- Report the number of words exported to Anki.
- Report how many selected Discover books were skipped because they already
  existed in the library.
- Correct the Anki export response type so frontend and Android builds compile.

## Migration notes

- No data migration is required when upgrading from rc.3.
- Portable JSON backups still omit PDF page images and other binary media.
- DEB uses `1.0.9~rc.5`, so it sorts after rc.3 and before final `1.0.9`.
