# Word Hunter 1.0.9-rc.7

This release candidate removes background folder synchronization. Syncthing and
the old shared-JSON merge path were too complex to maintain reliably across
desktop and Android storage restrictions. Transfers are now explicit, portable,
and reviewable.

## Changes

- Replace the Sync tab with Export on desktop and Pocket.
- Export all books, words, settings, progress, and book images as one ZIP package.
- Export vocabulary-only packages or Anki-compatible TSV files.
- Import packages through native file pickers without broad Android storage access.
- Store each word as a separate YAML file and each book as `book.yaml` with an
  adjacent image folder.
- Merge records using the `updatedAt` timestamp inside YAML, never filesystem
  modification time; local data wins ties.
- Include rendered PDF page images so desktop books remain readable on Pocket.
- Migrate legacy JSON record files to YAML while preserving small internal JSON
  UI-state and recovery journals.
- Remove Syncthing code, binaries, notices, package dependencies, UI, and tests.
- Require a successfully saved full ZIP package before destructive local clears.

## Migration notes

- Existing local JSON records are migrated to YAML on startup.
- Existing Syncthing folders are no longer read or written.
- Create a full ZIP package on the source device, then import it on the target.
- Import never removes unrelated local records.
- DEB metadata uses `1.0.9~rc.7`, so it sorts after rc.6 and before final `1.0.9`.
