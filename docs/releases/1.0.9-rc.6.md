# Word Hunter 1.0.9-rc.6

This release candidate fixes a recovery deadlock discovered while importing a
complete JSON backup on Android after a local text record became unreadable.

## Changes

- Validate projected text records before creating an interrupted-save journal.
- Prevent a failed projected-text save from leaving a journal that blocks later
  backup imports, synchronization, and recovery.
- Add an explicit backup-restore path that can replace an older unhydratable
  save journal after the imported text bodies have been validated.
- Let complete JSON backups repair unreadable local text records even when the
  imported content matches the last known frontend snapshot.
- Keep ordinary projected saves fail-closed so missing book text and PDF OCR
  pages are never silently overwritten.

## Migration notes

- No data migration is required when upgrading from rc.5.
- A JSON backup that previously failed with `cannot hydrate projected text
  record` can be imported again after installing rc.6.
- Portable JSON backups still omit PDF page images and other binary media.
- DEB metadata uses `1.0.9~rc.6`, so it sorts after rc.5 and before final
  `1.0.9`.
