# What's new in 1.0.12

**1.0.12 stable** — the Discover fix plus the Graphs overhaul.

## Discover fixed for everyone

The local web server's Content Security Policy (`connect-src 'self'`) blocked every external API call in production — book search and Wikipedia failed for all users (#241). The header now allows HTTPS APIs; verified live in the webview (CDP).

## Graphs overhaul (audit-driven)

- **Due forecast projects the coming days** — every due card gets a simulated "good" review through its own scheduler (SM2/FSRS), so the chart shows what's coming, not just today (#248)
- **Graduation at 21-day maturity** — cards now reach "known" when their interval hits 21 days instead of after two good ratings; the review queue builds properly and ease factors actually drift (#243)
- **Mature/young counts known cards** — known cards are the mature cohort; the chart is no longer permanently one-sided (#244)
- **Day-of-week chart counts real reviews** — was counting addition dates for never-reviewed cards (#247)
- **Consistent local calendar day** — forecast, stats, AI summary, heatmap and new-card defaults all use the local day (the UTC day shifted every bucket in the 00:00–02:00 window) (#246)
- **Readability** — larger labels, tooltip clamped to the viewport, no label/subtitle overlap, shorter interval labels (#245)
- **FSRS scatter spans the real stability range** — known cards carry the top stability values and now shape the axis (#249)
