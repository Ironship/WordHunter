# What's new in 1.0.11

Word Hunter 1.0.11 hardens Android reliability and continues the renderer migration.

- **Android**: minSdk raised to Android 8.0 (API 26), day/night theme support, a watchdog for the background service, and improved file-open flows.
- **Renderer migration**: settings, import, library, and reader/translator panels are now TypeScript renderers.
- **Argos download dialog** redesigned and ported to the renderer.
- **Release CI**: AAB version identity is verified by parsing the bundle manifest directly (aapt2 from newer build-tools cannot read AGP 8.11 bundles); the macOS DMG smoke test tolerates runner mount flakiness.
