## What's new in 1.0.10

**Contextual AI explanations for words and phrases** — the reader can now explain any word or phrase with an LLM, in context:
- Streamed answers from any OpenAI-compatible service (endpoint, model and API key are configurable in Settings)
- Reasoning-effort levels (`minimal` … `max`) for models that support them
- **Auto-trigger**: with the setting enabled, words that never had an explanation get one automatically the moment their panel opens
- Finished explanations are appended to the word's note (never overwriting your own text)
- Optional visual context for scanned PDF pages (vision-capable models)
- Local explanation cache + a translator button for quick re-explains
- Markdown rendering (**bold**, *italic*, `code`, lists) with strict HTML escaping

**Translation reliability** — retries, race protection and per-word failure cooldown for automatic word and sentence/context translation.

**Other fixes** — duplicate durable saves no longer block application shutdown.
