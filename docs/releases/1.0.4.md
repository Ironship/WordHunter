# Word Hunter 1.0.4

> Retro-active notes reconstructed from git history (2026-08-23) — original release predated the notes convention.

A maintenance release that fixes Windows saves and startup recovery after
settings changes, and gives Pocket a clear message for scanned PDFs.

## Fixes

- **Windows saves** — settings and library changes persist correctly on
  Windows.
- **Startup recovery after settings changes** — the app starts cleanly when a
  previous settings change left it in a bad state.

## New

- **Pocket explains scanned-PDF limits** — importing an apparently scanned
  file on Pocket now shows a dialog: PDFs without selectable text need OCR in
  the PC version, then sync to Pocket.

## Known issues

- None reported.
