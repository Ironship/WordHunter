# Word Hunter 1.1.0-rc.6

Sixth release candidate of the 1.1.0 line — three reader and vocabulary
improvements requested after the rc.5 review, on top of rc.5.

## New

- **Editable saved words** — the vocabulary editor now lets you change the
  word itself, not only its translation or status. Renaming keeps the word's
  learning progress, note, and examples; renaming onto a word that already
  exists is rejected with a clear message instead of merging entries.
- **Notes stay clean** — saving an AI explanation into a note that already
  has content now asks first: append the explanation at the end, replace the
  whole note, or cancel. Repeating an identical explanation still never
  duplicates (unchanged from earlier releases).

## Fixes

- **Eye toggle hides underlines on Android** — in the pocket layout the
  per-status underline styles loaded after the toggle's override and kept
  winning; they are now explicitly outranked, so hiding word underlines works
  on Android as it already did on desktop.

## Known issues

- Discovery card formatting still needs a visual repro before a targeted fix.

## Upgrade notes

- Install this build over rc.5 directly; no data migration is involved.
