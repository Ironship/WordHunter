# Word Hunter 1.0.9

> Retro-active notes reconstructed from git history (2026-08-23) — original release predated the notes convention.

The largest 1.0 maintenance release, distilled from eleven release
candidates: export progress on PC, a broad Android usability pass, a new
interface language, and robustness fixes across transfer and startup.

## New

- **PC export progress bar** — exporting your data shows a background job
  with a stage-based 0–100% indicator instead of a frozen window.
- **Android usability pass** — PDF import shows progress and can be
  cancelled, the word sheet supports pull gestures, landscape layout returns,
  startup is faster, and TTS pause/resume works in the background.
- **Chinese (Simplified) interface** — a zh locale joins the interface
  languages; untranslated page info in German, Spanish, and French is fixed.

## Fixes

- **PC startup with a missing data folder** — when the configured data folder
  is unavailable, Word Hunter falls back to the default location and reports
  the problem in a native dialog instead of failing silently.
- **Large book transfers** — the per-entry transfer limit rises to 64 MB so
  big OCR book records sync without errors.
- **Robustness hardening** — subprocess timeouts, TTS limits, cache cleanup,
  and splitting of oversized book packages prevent hangs and crashes seen in
  earlier builds.

## Known issues

- None reported.
