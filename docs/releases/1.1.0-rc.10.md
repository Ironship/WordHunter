# Word Hunter 1.1.0-rc.10

This release candidate completes the WordHunterWoW 1.2 import path for learning
German from World of Warcraft quest text.

## New

- **Import personal notes** — notes entered for a word in WordHunterWoW are
  copied into the standard Word Hunter note field.
- **See import progress** — the import control stays busy while the file is
  parsed and shows the current and total count during automatic translation.
- **Read current and legacy exports** — the importer supports the new `WHW2`
  note format and the numeric trailing metadata found in older `WHW1`
  SavedVariables files.

## Data safety and repeat imports

- Separate note timestamps keep newer Word Hunter notes from being overwritten
  by an older addon export.
- Re-importing the same SavedVariables file updates existing vocabulary entries
  and does not duplicate the same quest context.
- The importer reads only a strictly validated, versioned payload. It never
  executes Lua and rejects malformed records and files over 8 MiB.
- Import errors and cancelled reads restore the import control instead of
  leaving it in a busy state.

## Compatibility

- Use WordHunterWoW 1.2.0 for notes and the `WHW2` export format.
- Existing `WHW1` exports remain importable but do not contain personal notes.
- Synchronisation remains one-way from WordHunterWoW to Word Hunter.
