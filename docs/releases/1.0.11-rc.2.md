# What's new in 1.0.11-rc.2

**Bug-fix release candidate on top of 1.0.11-rc.1** — fixes four user-reported issues:

- **Word statuses now survive a restart** — a change made in the vocabulary/reader panel (e.g. setting a word to *learning*) is persisted; previously the autosave delta could silently drop the change and the old status came back after quitting. The dirty-tracking now attributes root vocabulary mutations to the active language, and any un-attributed mutation falls back to a full snapshot instead of an empty delta.
- **Discover no longer shows "Could not fetch results" on flaky connections** — search fetches (Gutenberg and Wikipedia) now have a bounded timeout with one retry, instead of hanging indefinitely and failing on slow/Cloudflare-throttled networks.
- **The Settings tab is no longer blank** — the settings view is mounted inside the main panel (`.main-panel`) like every other view; it was previously appended to `document.body` below the fold.
- **OCR self-test no longer falsely reports a failed GPU** — the GPU probe now honors the runner's verdict even when the probe process exits non-zero, and the probe deadline was raised (120 s). On DirectML systems (e.g. RTX 4090) the app now correctly reports the GPU instead of falling back to CPU.

Everything from 1.0.11-rc.1 is included (Android reliability, HTML→TS portability wave, F-Droid readiness).
