# Word Hunter 1.1.0-rc.5

Fifth release candidate of the 1.1.0 line — bugfix follow-up to rc.4 (tag `WordHunter1.1.0-rc.4`).

## Changes since 1.1.0-rc.4

- **Discovery: Wikipedia + Wikinews back** — only Wikisource was meant to be removed; the MediaWiki client is restored for Wikipedia and Wikinews, the source selector keeps Gutenberg/Wikipedia/Wikinews, and the persisted `wikisource` selection migrates to Gutenberg. Formatting of the Discovery cards is left for a visual repro.
- **Flashcards: shuffle button off the centre** — the chip now lives in a compact trailing row of the review header instead of stretching full-width in the middle of the view (pocket + narrow layouts).
- **Reader: find bar** — opening the in-text search hides the magnifier button so it no longer covers the close button (`pocket-only-control` → `hidden` while the bar is open).
- **Reader: bookmarks** — jumping to a bookmark reliably scrolls the word into view (`focus({preventScroll:true})` → `keepReaderTokenVisible`); fixes the PC-only "no jump" case.
- **Reader: TTS follow-along** — bounded tracking: exact matches searched only in the next 12 tokens, resync looks only at upcoming runs of the current sentence, 24-token window, max 2 resyncs per sentence. Prevents the yellow outline from walking across the book after a long word.
- **Reader: eye toggle** — no code change in this candidate (static analysis shows the `no-token-highlight` path is correct); left flagged for a runtime repro on Android/PC as requested.
- **Library: delete** — custom-text removal no longer downloads a full store snapshot; the confirmation dialog has a 20 s safety timeout with a background-continue toast instead of hanging forever.
- **Release notes hygiene** — `docs/releases/TEMPLATE.md` added with a pre-publish checklist forbidding CI output and AI-styled copy.
- **Tests/i18n** — restored `discover/library.sourceWikipedia|sourceWikinews` keys across 10 locales, allowlist and stylesheet budget pins updated.

## Verification
