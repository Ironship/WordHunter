# Word Hunter 1.1.0-rc.8

Maintenance release on the 1.1.0 line: internal reliability work, no new
features.

## Fixes

- **Long network operations keep their budget** — every backend call now
  carries an explicit timeout sized to the operation (AI explanations 90 s,
  model downloads and library transfers up to 10 min). Previously a generic
  short deadline could silently abort these mid-flight.

## Internal

- Backend request routing and the settings screen are reorganised into
  focused modules with identical behaviour.
- Network calls go through one authenticated client with consistent token
  handling.

## Known issues

- Discovery card formatting still needs a visual repro before a targeted fix.
