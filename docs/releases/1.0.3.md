# Word Hunter 1.0.3

> Retro-active notes reconstructed from git history (2026-08-23) — original release predated the notes convention.

This release repairs Android imports and makes OCR on scanned PDFs more
dependable, with visible progress and corrections limited to the sentence
you select.

## Fixes

- **Android import controls work again** — book import controls on Pocket
  respond as expected.
- **OCR reliability** — scanned-PDF text recognition is steadier across a
  full import.
- **Stable counters and progress animation** — page and progress indicators
  no longer jump around while OCR runs.

## New

- **Sentence-only PDF corrections** — after OCR, you correct just the
  selected sentence instead of re-editing the whole page.

## Known issues

- None reported.
