# Word Hunter 1.1.0-rc.1

First release candidate of the 1.1.0 line.

## Changes since 1.0.13

- **Boot locale race fixed** — the saved language reliably wins over the
  navigator language at startup (loader latest-wins + reconcile-after-state
  bridge snapshot, `#275`/`#274`), and the add-word dialog re-renders its
  strings when the language changes.
- **Keyboard and screen-reader accessibility** — panel resizer is keyboard
  operable with ARIA values, a skip link is available, focus is returned to
  the page on render and to the reader token after the word panel closes,
  and Escape/Arrow keys work in review (`#6`).
- **Reliable OCR fallback** — the CPU-fallback path now rendezvous through a
  release file instead of racing with the GPU pass (`#268`).
- **Review heatmap** — today is resolved in the local timezone and labels,
  months, and legend typography are sharpened (10→11 px).
- **Storage healthy** — oversized journal saves are rejected before writing,
  journals rotate, and `QuotaExceeded` falls back to a prefs-only envelope.
- **UI polish** — accent contrast raised to AA, visible focus ring on blue
  chrome, and 44 px touch targets for round controls.
- **Locales** — plural forms (`_one`/`_few`/`_many`/`_other`) across all 10
  languages.
