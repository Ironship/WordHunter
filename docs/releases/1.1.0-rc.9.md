# Word Hunter 1.1.0-rc.9

This release candidate connects Word Hunter with the WordHunterWoW addon for
learning German from World of Warcraft quest text.

## New

- **Import German quest vocabulary** — the Export screen can read the strict
  `WordHunterWoWExport` value from the addon's SavedVariables file.
- **Keep learning data and context** — imported words retain their status,
  manually entered meaning, and quest sentence. Repeated imports update the
  existing entry without duplicating the same context.
- **Fill missing meanings automatically** — when automatic translation is
  enabled, empty meanings are processed sequentially by the configured Google,
  DeepL, LM Studio, or offline translation provider.

## Safety and reliability

- The importer never executes Lua. It accepts only the versioned `WHW1` data
  payload, validates statuses and timestamps, and rejects files over 8 MiB.
- Newer Word Hunter status or translation edits are preserved when an older
  SavedVariables file is imported.
- Switching language profiles during import or translation cannot write a
  German result into another profile.

## Known limitation

- Synchronisation is currently one-way from WordHunterWoW to Word Hunter.
  Status changes made later in Word Hunter are not sent back to the addon.
