# Word Hunter 1.1.0-rc.7

Maintenance release on the 1.1.0 line: internal quality work with no new
features and no user-visible behaviour changes.

## Internal

- **Import pipeline reorganised** — the former single-file import module is
  split into focused submodules (panel rendering, YouTube captions, PDF/OCR,
  file loaders, event binding) behind the same public interface.
- **Record storage reorganised** — the record persistence module is split by
  cohesion (model, fingerprints, causal ordering, payload, merge, IO) with
  unchanged call sites.
- **Styles consolidated** — repeated declaration groups merged into shared
  rules; rendered appearance is unchanged.
- **Performance guard** — a new automated test exercises library statistics
  at large-library scale (200 books) and fails if preparation or cached
  lookups regress beyond generous budgets.
- **AUR version tracking** fixed; retro-active release notes added for
  historical tags.

## Fixes

- None user-facing in this cycle.

## Known issues

- Discovery card formatting still needs a visual repro before a targeted fix.
