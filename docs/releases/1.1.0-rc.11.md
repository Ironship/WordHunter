# Word Hunter 1.1.0-rc.11

This release candidate adds encounter history for vocabulary imported from
WordHunterWoW 1.3.

## New

- **See encounter history** — imported words retain their first-added date,
  last-seen date, status-change date, and number of different WoW quests in
  which they appeared.
- **Spot words that may be learned** — a Learning word seen in at least five
  quests over fourteen days receives a `Ready for Known` suggestion in the
  vocabulary list and word editor. Word Hunter never changes the status
  automatically.
- **Read `WHW3` exports** — the importer accepts WordHunterWoW 1.3 encounter
  metadata while remaining compatible with `WHW1` and `WHW2` files.

## Data safety and repeat imports

- Re-importing the same SavedVariables file uses the earliest first-added
  date, latest last-seen date, and highest encounter count. It does not count
  the same exported encounters again.
- Statuses, meanings, notes, and quest contexts keep the timestamp and
  duplicate-protection rules from earlier release candidates.
- The importer strictly validates the versioned text payload and never
  executes Lua.

## Compatibility

- Use WordHunterWoW 1.3.0 for the `WHW3` encounter-history format.
- Existing `WHW1` and `WHW2` files remain importable but do not contain
  encounter history.
- Synchronisation remains one-way from WordHunterWoW to Word Hunter.
