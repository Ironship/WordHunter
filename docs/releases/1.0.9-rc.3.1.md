# Word Hunter 1.0.9-rc.3.1

> Retro-active notes reconstructed from git history (2026-08-23) — original release predated the notes convention.

A single-fix hotfix on top of 1.0.9-rc.3 for an Android startup deadlock.

## Fixes

- **Android startup deadlock** — a pending snapshot write could hold the
  store lock while the app waited on it during launch; the snapshot is now
  deferred until the library finishes loading.
- **Everything from rc.3** — this build carries all 1.0.9-rc.3 changes
  unchanged.
