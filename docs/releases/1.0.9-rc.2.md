# Word Hunter 1.0.9-rc.2

The second 1.0.9 release candidate keeps all rc.1 fixes and focuses on Android
startup and flashcard reliability based on extended user testing.

| # | Issue | Fix |
|---|-------|-----|
| 1 | Android still takes too long to start | **Concurrent startup state loading** — the initial HTML no longer waits for a complete store snapshot. State loading starts immediately and overlaps frontend, locale, and book-catalog loading. |
| 2 | Flashcards can stop accepting a grade after dozens of reviews | **Guarded grading with timeout fallback** — only one grade can be active, controls show a busy state, and a stalled native request falls back to the local scheduler after four seconds. |
| 3 | Grade feedback sound is intermittent | **Sound for every accepted grade** — grades 1 through 5 have distinct short tones independent of vocabulary status changes, with resumed AudioContext handling and node cleanup. |
| 4 | Flashcard image-removal icon has incorrect proportions | **Shared square removal control** — accessible 24 px desktop and 44 px Android touch targets. |
| 5 | New flashcards are not read automatically | **Automatic pronunciation toggle** — enabled by default, reads each newly presented card once, and waits for answer reveal on reverse cards. |
| 6 | Recall buttons wrap to two rows | **Five-button single row** — full flashcards now use the same 1-5 scale as Reader cards. |
| 7 | Previous and Next split across rows | **Grouped navigation** — both controls remain together in one responsive row. |
| 8 | Today's cards are ordered rather than shuffled | **Stable shuffled sessions** — Fisher-Yates shuffle runs once per day/profile session and remains stable across answer reveals and rerenders. |

## Migration notes

- No data migration is required when upgrading from rc.1.
- Automatic flashcard pronunciation is enabled by default and can be disabled
  in Settings → Flashcards.
- DEB uses `1.0.9~rc.2`, so it sorts after rc.1 and before final `1.0.9`.
