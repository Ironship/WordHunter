# Word Hunter 1.0.9-rc.3

The third 1.0.9 release candidate keeps all rc.2 fixes and adds performance
improvements, cache optimizations, and TTS fixes across the Reader, PDF
navigation, indexing, caching, and networking layers.

| # | Issue | Fix |
|---|-------|-----|
| 1 | Word selection re-tokenizes the entire book | **Reader word selection no longer re-tokenizes entire book** — word lookup is now scoped to the active page instead of scanning the full text. |
| 2 | PDF page navigation is O(n) | **PDF page navigation uses cumulative offsets** — page positions are precomputed, making navigation O(1) instead of scanning every page. |
| 3 | Rust phrase indexing scans linearly | **Streaming tokenizer with trie matching** — phrase index construction streams tokens and matches against a compiled trie instead of re-scanning. |
| 4 | Index cache can serve stale or corrupt data | **Index cache fingerprints content** — cache keys now use content fingerprints instead of sampling, detecting changes reliably. |
| 5 | UI state saves produce multiple serialization passes | **UI state saves are coalesced** — multiple save triggers within a short window are merged into one serialization. |
| 6 | Book body cache evicts active Reader pages | **Book body cache pins active Reader** — the currently displayed page is pinned and not evicted while the Reader is open. |
| 7 | Library statistics block hydration | **Library statistics hydration loads and computes stats concurrently** — stats are calculated in parallel with the initial render. |
| 8 | Edge TTS can hang or mix sessions | **Edge TTS timeout safety, session isolation fixes** — each TTS session has its own timeout guard and session state is isolated. |
| 9 | Request deadlines do not cover response body reads | **Request deadlines cover response body reads** — timeouts now include the full response body read, not just the initial connection. |
| 10 | Static assets are fully buffered in memory | **Static assets and media streamed from disk** — files are served as streams instead of being read entirely into memory first. |
| 11 | HTTP agent created per request | **HTTP agent reused globally** — a single connection pool and user agent is shared across all requests. |
| 12 | Frontend bundle is unminified | **Minified frontend bundle** — syntax and whitespace minification applied to the production build. |
| 13 | No test regression guard | **298 Rust tests, 458 frontend tests pass** — full validation gate confirmed. |
