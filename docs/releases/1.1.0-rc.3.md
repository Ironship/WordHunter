# Word Hunter 1.1.0-rc.3

Third release candidate of the 1.1.0 line (rc.2 was never published — its
versionCode is superseded by this one).

## Changes since 1.1.0-rc.1 / rc.2

All changes from the `exp/theme-deai-rc3` UI campaign:

- **UI audit pass** (`d2d75fc`) — unified 38 px desktop button scale, visible
  keyboard focus on panel resizers, narrow-window Actions column yield
  (376→308 px below 780 px), toasts raised above the fullscreen export
  overlay, dead translator Copy handler removed, decorative gloss/gradient
  removed from flashcard and OCR panels, radius literals unified onto tokens,
  `vocab.noResults` translated in all 9 non-English locales.
- **Faster book saving** (`16ec128`) — book edits and library operations now
  request the merged snapshot in the save response itself
  (`/__store/save?snapshot=1`): one round trip instead of save + full-store
  GET (~store-size download skipped per save). Behavior-preserving fallback
  retained for older in-flight saves.
- **Markdown-lite formatting** — **bold** and *italic* markers editable via a
  B/I format bar in the Edit Book dialog; markers are stripped before
  tokenization so vocabulary identity, offsets, and TTS are unchanged, and the
  Reader renders formatted spans inline.
- **Consistent busy indicators** — words+chars counter under the edit textarea
  and spinner states on Save/Add-word confirm buttons.
