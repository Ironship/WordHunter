# What's new in 1.0.12-rc.1

**Hotfix release candidate** — fixes the root cause of Discover being broken for every source:

- **Discover now actually fetches results** — the app's local web server hardcoded `connect-src 'self'` in its Content-Security-Policy header, so the webview blocked EVERY external request (Gutenberg, Wikipedia, thumbnails) before it left the machine. The header now allows external https APIs and local LM Studio. Verified live in the webview (CDP): both sources return results.

Everything from 1.0.11 is included.

## Verification

- 617 frontend tests + 289 Rust tests (incl. new CSP-header assertion), all green
- Live webview proof: gutenberg + wikipedia search return 200 and render results
- Full release pipeline: 8 artifacts (Android versionCode 101001201)
