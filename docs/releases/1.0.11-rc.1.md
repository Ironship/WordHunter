# What's new in 1.0.11-rc.1

**Android reliability and interface cleanup** — this release line finishes the HTML→TS portability wave (dialogs, import panel, library filter bar, and the whole settings view are now rendered by TypeScript components with no duplicated static markup) and hardens the Android runtime:

- **TTS word highlighting works on modern Android versions** — the range-start callback ported to the current SDK (minSdk raised to 26)
- **Day/night themes follow the system** on Android
- **Exporting no longer stalls** on a busy database — busy-rejection with a clear message
- **Faster startup after background restarts** — boot watchdog + `onNewIntent` handling
- **Youglish opens through the native Android bridge** (with the desktop fallback intact)
- **Wipe now requires explicit confirmation**
- **F-Droid readiness** — version-neutral committed Android project (`gen/android`) with a portable prepare script
- **Portability contracts** — CSS size budget, theme-token parity, and fallback guards keep the frontend honest

## Verification

- 613 frontend tests (incl. renderer contracts for every ported dialog/panel, repo-validation wiring, i18n parity across 10 locales) + 282 Rust tests, all green
- Full release pipeline: 8 artifacts (signed Android debug APK + release AAB, Windows portable.zip + Setup.exe, macOS aarch64 DMG, Flatpak bundle, Linux AppImage + DEB)
