# Word Hunter 1.1.0-rc.2

> Retro-active notes reconstructed from git history (2026-08-23) — original release predated the notes convention.

The second 1.1 release candidate focuses on storage safety, steadier local
serving, lighter ebook imports, and interface/accessibility polish.

## Fixes

- **Safer atomic writes** — temporary files for atomic writes are never
  followed through symlinks, protecting the library from tampering on shared
  machines.
- **Steadier local serving under load** — the built-in server uses a fixed
  worker pool instead of one thread per request, keeping responsiveness
  predictable.
- **Lighter ebook imports** — EPUB imports stream instead of double-buffering
  the whole file, avoiding large memory spikes.
- **Data folder override on Windows** — overriding the data location via the
  APPDATA environment variable works again.

## New

- **Interface and accessibility polish** — larger row action targets in the
  vocabulary table, correct dark-theme gradients, aligned topbar counters,
  clearer empty states, a cleaner startup without the initial flash, and
  reliable keyboard/screen-reader focus handling in the reader.

## Known issues

- None reported.
